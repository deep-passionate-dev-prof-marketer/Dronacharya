# Features & Functionality Guide
## Dronacharya: Complete Capabilities, Remote Control Matrix & Room Bomber Specifications

**Document Version:** 2.4.0  
**Target Platform:** 21K School Dronacharya & 21K Learning Floww

---

### 1. Dedicated Multi-Role Portals & Authentication
1. **Teacher / Facilitator Portal (`/login/teacher`)**:
   - Academic authentication with Department and Section routing.
   - Master lecture stage controls: Mute All, Screen Share, Whiteboard, 3D STEM Visualizer.
   - Remote screen request and intervention controls across student devices.
   - Real-time attendance ledger and AI lecture summarizer trigger.
2. **Student & Parent Portal (`/login/student`)**:
   - Combined student and parent attendee registration.
   - Device selection (Smartphone, Tablet, Laptop, Desktop).
   - Bidirectional remote help offer/request.
   - NotebookLM concept graph and interactive derivations.
   - Auto-routing when a Room Bomber pitch session is initiated.
3. **Auditor Portal (`/login/auditor`)**:
   - Compliance inspector console with inspection cohort selection.
   - Silent room observation across active classes.
   - Facial landmark gaze tracking and SNR audio acoustic metrics.
   - Standardized 4-pillar pedagogical rubric scoring (Delivery, Inclusivity, Clarity, Engagement).
4. **Administrator & Sales Director Hub (`/login/admin`)**:
   - Executive operations oversight and system topology monitor.
   - Automated rule engine for class failover and teacher substitute dispatch.
   - 1-Click **Room Bomber 1:1 Sales Engine** with custom ratio configuration.
   - Real-time sales pitch matrix and closing analytics.

### 2. Multi-Device Remote System Access Cockpit
- **Supported Form Factors**:
  - **Smartphone**: 9:16 mobile viewport (Android / iOS) with portrait scaling, touch taps, mobile terminal, and worksheet viewing.
  - **Tablet**: 4:3 high-resolution display with precision stylus annotation, palm rejection simulation, and drawing overlay.
  - **Laptop**: 16:10 workspace with code editor, terminal logs, and multi-tab browser simulation.
  - **Desktop PC**: 16:9 ultra-wide workstation with multi-monitor tabs, full remote control, and hardware accelerated computing.
- **Granular Permission Levels**:
  - **View Only**: Passive screen viewing with FPS, latency, and resolution telemetry.
  - **Annotate**: Real-time collaborative pointer, pen tool with customizable colors, and highlighter.
  - **Full Control**: Full bidirectional remote input: mouse pointer movements, click events, keyboard typing, terminal commands, and answer edits.
- **In-Meeting Quick Controls**:
  - Instant input muting to prevent accidental interference.
  - 1-Click canvas wipe and annotation reset.
  - Interactive application switcher (Worksheet, IDE, Terminal, Browser, Scientific Calculator).
  - Multi-device tab switching: Jump seamlessly between a student's phone, tablet, laptop, and desktop.

### 3. Room Bomber 1:1 Sales Conversion Engine
- **Automated Room Partitioning**:
  - Automatically identifies all prospective students and parents in the main demo hall.
  - Instantly allocates an isolated breakout room for each prospect (e.g., `Pitch Room #1 - Alpha`, `Pitch Room #2 - Beta`).
  - Assigns exactly one dedicated sales counselor to each family room.
  - Dispatches WebSocket instructions to automatically move users into their designated rooms without manual intervention.
- **In-Room Sales Pitch Heads-Up Display (HUD)**:
  - **Prospect Intelligence Card**: Displays student grade level, parent attendee details, contact email/phone, and target academic objectives.
  - **5-Stage Guided Script Flow**:
    1. *Stage 1: Rapport & Academic Diagnostic* (Uncover student's current school challenges).
    2. *Stage 2: Live Curriculum & Tech Showcase* (Demonstrate interactive 3D simulations and remote control).
    3. *Stage 3: Pedagogy & Global Accreditation* (Highlight Cambridge & IB alignment and Harvard faculty pedagogy).
    4. *Stage 4: Tuition Calculator & Spot Scholarship* (Interactive tuition builder with 1-click 25% Founder's Scholarship authorization).
    5. *Stage 5: Instant Enrollment Close & Contract* (Digital enrollment contract generation with immediate seat confirmation).
  - **Real-Time Parent Engagement Meter**: Live feedback score derived from camera attention and audio responsiveness.
  - **Master Admin Matrix**: Live command center displaying all active pitch rooms, current sales stage, discount status, and 1-click "Recall All to Main Hall".

- **3D Interactive Bloch Sphere Visualizer**: Real-time quantum qubit state vector manipulation with unitary gates ($H$, $X$, $Y$, $Z$).
- **Collaborative Whiteboard**: Multi-user freehand vector drawing, geometric shapes, sticky notes, and instant clearing.
